# Internationalization

Product UI will support three locales. This document is a plan only; no locale files or i18n libraries are in the repository yet.

## Locales

| Code | Language | Role |
| --- | --- | --- |
| `en` | English | Source locale |
| `ja` | Japanese | Same message keys as English |
| `ko` | Korean | Same message keys as English |

Repository docs and GitHub templates stay English-only.

## Future layout

When each package is scaffolded:

- **Frontend (Vite):** a shared message catalog keyed by the same IDs for `en`, `ja`, and `ko`.
- **Backend (Rails):** `config/locales/en.yml`, `config/locales/ja.yml`, and `config/locales/ko.yml`.
- **Extension (Chrome):** `_locales/en`, `_locales/ja`, and `_locales/ko` with `messages.json`.

Do not hardcode user-facing strings in application code once those packages exist. Do not add i18n libraries in this initial setup.
